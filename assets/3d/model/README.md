# 差し替え用 3D モデル置き場（GLB）

threejsassets.com の無料モデル（アカウント登録でダウンロード可）を、下のファイル名で置くと差し替え候補になります。
いまのゲームはまだ読み込み処理を入れていないので、置いてもらったら組み込みます。

| ファイル名 | 元のモデル（slug） | 置き換える物 |
|---|---|---|
| steel-locker.glb | steel-locker | 合流後のスタッフ用ロッカー |
| vending-machine.glb | vending-machine | 合流後の古い自販機 |
| desk.glb | desk | 待機室の管理机 |
| desk-chair.glb | desk-chair | 事務椅子 |
| desk-lamp.glb | desk-lamp | 机のアームランプ |
| bench-01.glb | bench-01（または park-bench-01） | 合流後のベンチ |
| bookshelf.glb | bookshelf | 資材庫の棚・返却棚 |
| car-sedan-01.glb | car-sedan-01 | 外の街の車 |
| street-lamp-01.glb | street-lamp-01（または realistic-street-lamp-01） | 外の街灯 |

消火器・ハト・バケツ・段ボール・時計（無料）は同サイトに見当たらなかったので、別の CC0 サイト（Poly Haven / Quaternius など）の候補です。
